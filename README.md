## 01. QC 검사보고서 자동화

**문제**: 선적 건마다 제품 사진과 정보를 엑셀에 수기로 입력해 보고서를 만들어야 했고, 건당 3시간 이상 걸리는 반복 업무였습니다.

**한 일**
- 기존 작성 구조를 바탕으로 단계별 요구사항을 정의하고, Claude AI로 HTML 기반 자동화 툴(QC Report Generator)을 직접 기획·구현
- 사용하면서 나온 오류(사진 번호 입력 오류, 형식 오류, 추가 기재 사항 등)를 코드 단위로 계속 디버깅·개선
- 팀장과 협의해 실무에 적용

**결과**
- 보고서 작성 시간 **3시간 → 30분 (약 83% 단축)**
- 현재도 반복되는 선적 건에서 실제로 사용 중

**배운 점**: 업무를 데이터 구조(제품 정보·이미지·검사 결과·치수/중량)로 나눠 보면 자동화할 수 있는 단위가 보인다는 것, 그리고 AI 활용 → 구현 → 검증 → 개선을 반복하는 과정

## 02. 온라인 쇼핑몰 거래 데이터 분석

- **형태**: 개인 프로젝트
- **데이터**: 1,000건 주문, 292명 고객
- **도구**: Python(pandas), Tableau 대시보드

**데이터 품질 점검**: 결측치와 unique 값을 점검하고, `Unit Price × Quantity = Total Price` 검증용 파생변수로 **단가 2배 오기재 등 오류 20건**을 찾아 보정했습니다.

**분석**
- 구매빈도 × 평균주문금액 **2×2 매트릭스로 고객을 4개 군으로 분류**
- 카테고리별 매출, 월별 매출 추이 분석

**인사이트**
- "저빈도 × 고단가" 그룹은 고객 수가 중간 수준이지만 총매출 기여도가 가장 높음 → 자주 사는 것을 유도하기보다 **객단가가 높은 고객의 리텐션**이 중요
- Electronics와 Accessories는 고객 수·주문 건수가 비슷한데 단가 차이(약 14.36배)로 매출 격차(16.6배)가 발생 → **매출은 수량보다 객단가가 좌우**
- 단기 데이터라 뚜렷한 시계열 패턴은 확인되지 않음(11월 매출 최고점은 확인)

**제안**: 고객군별 차별화 전략(재구매 주기 관리, 업셀링·크로스셀링), 객단가/주문 물량에 따른 상품 구성 전략, 입력 단계의 자동 검증 로직 도입

**한계**: 제안한 전략을 실제로 검증하지는 못했고, 단기 데이터라 시계열 분석의 정확도가 낮음. A/B 테스트로 효과를 검증해 보고 싶음

## 03. 신발 브랜드 마케팅 메시지–소비자 반응 일치도 분석

- **형태**: 팀 프로젝트 (팀장)
- **질문**: 브랜드가 내세우는 소구 키워드(접지력, 스포티 등)를 소비자는 실제로 느끼고 있을까?
- **데이터**: 네이버 API(블로그) + Selenium 크롤링(스마트스토어, 공식 홈페이지), 5개 브랜드 × 약 2,000건
- **도구**: Python, Kiwi(형태소 분석), Word2Vec, WordCloud

**분석 흐름**
1. 전처리 파이프라인 구성: 정제 → 띄어쓰기·맞춤법 교정 → 품사 태깅 → 표제어·품사 추출 → 불용어 제거. 특이한 용어가 많아 `add_user_word()`로 **사용자 사전을 구축**해 정확도 확보
2. **Word2Vec으로 마케팅 키워드를 20개에서 59개로 확장** (유사도 상위 5개, 유사도 0.6 이상만 추가)
3. WordCloud, 감성 분석(긍정/부정 단어 사전 → 의미 확장 → 리뷰 매칭 → 감성 점수), 텍스트 분류(확장 키워드 매칭 → 최다 매칭 카테고리를 리뷰 라벨로 지정, 매칭 0건은 "분류 불가"로 처리해 신뢰도 확보)


**브랜드별 인사이트**

| 브랜드 | 소비자 반응 | 마케팅 방향 제안 |
|---|---|---|
| 나이키 | 감성 · 핏 · 디자인 | 비주얼 중심 콘텐츠 강화 |
| 뉴발란스 | 디자인 · 소재 · 외형 | 소재/디테일 강조 |
| 살로몬 | 부정 리뷰 상대적 증가 | 부정 리뷰 원인 검증 필요 |
| 아디다스 | 디자인 · 감성 | 제품 스토리텔링 강화 |
| 아식스 | 기능성 · 착화감 · 디자인 | 기능+감성 메시지 결합 |

**핵심 인사이트**: **Brand Value ≠ Consumer Perception.** 소비자는 착화감·쿠셔닝·디자인처럼 직접 체감한 것을 많이 언급하고, 브랜드가 내세운 기능성 소재·헤리티지 용어는 거의 쓰지 않았습니다(기능성 언급 0.1~0.8%). 기능성을 내세우는 데서 그치지 않고, 소비자가 자기 언어로 말하게 하는 고객 언어 기반 커뮤니케이션이 필요합니다.

**한계**: 부정 리뷰의 구체적 키워드는 정량 검증하지 못했고, 키워드 기반이라 문맥을 반영하는 데 한계가 있음 → 문맥 기반 모델로 확장 필요

## 04. 은행 정기예금 가입 예측

- **형태**: 팀 프로젝트 (팀장), 약 1개월
- **데이터**: Bank Marketing 고객 데이터 31,647행, 가입 비율 11.7%(불균형)
- **평가**: F1-score (불균형 특화 지표)
- **최종 모델**: LightGBM + CatBoost를 각각 Bagging한 뒤 Soft Voting으로 결합, **검증 F1 0.618**
- **비교한 방법**: `scale_pos_weight`, Bagging, Hard/Soft Voting, RandomizedSearchCV, SMOTE, OOF, Stacking (Hard Voting·SMOTE·OOF·Stacking은 과적합/낮은 성능으로 미채택)
- **역할**: 팀장으로 Kaggle 제출·회의·중간 점검 주도, 참여가 저조한 팀원에게 수행 가능한 업무를 구체적으로 배분

자세한 내용과 실험 로그, 한계는 **[04 프로젝트 README](./bank_term_deposit/README.md)**에 정리했습니다.

## 05. 직원 이직 요인 다변량 분석

- **형태**: 팀 프로젝트 (팀장)
- **데이터**: IBM HR Analytics Employee Attrition & Performance, 1,470명 · 35개 열

**분석 흐름**
1. **변수 선택·설계**: 개인·직무·보상·조직문화 4개 카테고리로 나눠 핵심 변수를 선택하고, VIF와 상관행렬로 다중공선성이 없음을 확인
2. **파생변수**: 데이터에 없는 '성장 가능성'을 `GrowthPotential2`(직급별 평균 역할 유지 기간과 개인 유지 기간의 차이)로 정량화. 값이 클수록 평균보다 빠르게 역할이 이동했다는 의미
3. **요인분석·군집분석**: 고유값 1 초과 요인들로 미리 정한 카테고리의 타당성을 확인하고, 계층적 군집과 K-means(엘보우 기법)로 비슷한 특성의 4개 집단 분류
4. **로지스틱 회귀 + 교호작용항**: 군집 패턴과 HR 이론을 근거로 월급×인상률, 근속×성장성 교호작용을 추가. Pseudo R² 0.153 → 0.165로 설명력 개선, 두 항 모두 유의

**주요 결과**
- 이직 위험을 높이는 요인: 초과근무(OR 1.96), 성장 가능성(OR 1.54), 통근 거리(OR 1.25)
- 이직 위험을 낮추는 요인: 월 소득(OR 0.51), 직무 만족도(OR 0.71), 월급×인상률 교호작용(OR 0.78), 근속×성장성 교호작용(OR 0.75) (OR는 1 표준편차 증가 시)
- K-means 결과 **저연봉·경력 초기 군집의 이직률은 약 19%로, 고연봉·장기근속 안정군(7.4%)의 약 2.5배**
- AUC 0.776 (전체 데이터로 학습·평가한 값)

**시사점**: 이직은 보상 × 성장성 × 근무환경이 결합된 결과이므로 핵심 인재 대상 차등 보상·인상률 전략, 승진 속도·직무 이동·경력개발 관리, 근무 방식 유연화(재택·하이브리드·배치 조정)가 필요합니다.

**한계**: 전체 데이터로 학습·평가해 일반화 성능은 검증하지 못했습니다. 이후 train/test 분할과 트리 기반 모델 등으로 확장할 계획입니다.

## 06. 계절성 투자전략 가설 검증 EDA

- **형태**: 팀 프로젝트 (팀원)
- **질문**: "5월에 팔고 11월에 사라(Sell in May)"는 격언은 실제로 유효한가?
- **방법**: 산업·경제·사회 전 분야에서 주가 영향 요인을 찾고, 팀원별로 영역을 나눠 공공데이터를 수집·정제(월별 시계열로 통합)한 뒤 지표별 월별 추이와 주가의 상관관계를 시각화·종합
- **역할**: 항공, 산업생산지수, 금리, 소비재(아모레퍼시픽) 지표와 주가의 상관관계 분석·시각화·결과 해석
- **결과**: Sell in May를 뒷받침할 뚜렷한 패턴은 확인되지 않음. 정치·자연재해·경제 등 5개 범주로 주가 변동 요인을 분석했고, 체계적인 검증 프로세스를 인정받아 **학회 경진대회 10개 팀 중 2위**
- **한계**: 실제 주가는 하나의 사건에도 여러 요인이 동시에 작용해 딱 떨어지는 해석이 어려움. 시각화 중심 EDA의 한계를 보완하기 위해 회귀분석 등 정량 검증으로 요인별 영향을 분석할 계획
