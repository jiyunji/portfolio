# 신발 브랜드별 마케팅 메시지 · 소비자 반응 일치도 분석 (살로몬 편)

> 브랜드가 내세우는 마케팅 메시지를 소비자가 실제로 그렇게 느끼고 표현하는지, **리뷰 텍스트 데이터로 검증**한 프로젝트

**팀 프로젝트 (5개 운동화 브랜드, 팀장)** · 이 저장소에는 본인이 담당한 **살로몬(Salomon XT-6)** 분석 코드를 게시합니다. 브랜드 간 비교 결과는 PPT 포트폴리오에 게시되어있습니다.

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 문제의식 | 브랜드가 강조하는 소구 키워드(접지력, 스포티 등)를 소비자가 실제로 체감하고 있는가? |
| 목표 | "브랜드가 말하는 것"과 "소비자가 느끼는 것"의 간극을 정량적으로 측정하고, 브랜드별 마케팅 방향 제안 |
| 담당 | 살로몬 XT-6, 아디다스 오즈위고 리뷰 수집 · 전처리 · 분석 |
| 데이터 | 네이버 블로그 리뷰 935건(살로몬) + 629건(아디다스) + 스마트스토어 리뷰 909건(살로몬) = **총 2,464건** |
| 도구 | Python, Selenium, BeautifulSoup, Kiwi, KoSymSpell, gensim(Word2Vec), WordCloud, matplotlib |

## 분석 흐름

```
데이터 수집 → 전처리 파이프라인 → 키워드 의미 확장 → WordCloud / 감성분석 / 텍스트 분류 → 브랜드 진단
```

### 1. 데이터 수집
- **블로그:** 네이버 검색 API로 게시글 링크를 모은 뒤, Selenium과 BeautifulSoup으로 본문을 추출하고 HTML 태그를 제거
- **스마트스토어:** Selenium으로 리뷰 페이지를 순회하며 구매 리뷰를 수집

### 2. 전처리 파이프라인
정제 → 띄어쓰기 → 맞춤법 교정 → 품사 태깅 → 표제어 추출 → 품사 추출 → 불용어 제거 순으로 구성

| 단계 | 내용 |
|---|---|
| 정제 | URL, 이모지, 숫자, 해시태그, 자음 반복(ㅋㅋ, ㅠㅠ), 특수문자 제거 |
| 띄어쓰기 | Kiwi 적용 |
| 맞춤법 교정 | KoSymSpell 적용, 고유명사·리뷰 용어는 사용자 지정 단어 사전으로 보호 |
| 품사 태깅 · 표제어 | Kiwi로 명사·동사·형용사 위주 추출 |
| 불용어 제거 | 분석에 불필요한 단어 제거 |

**사용자 사전 구축:** 일반 사전에 없는 브랜드·리뷰 특화 용어(살로몬, XT-6, 실착, 깔창, 네임택, 정사이즈, 반사이즈업, 내돈내산 등)가 많아 기본 형태소 분석기로는 교정 정확도가 낮아지는 문제가 있었고, `add_user_word()`로 사용자 사전을 구축해 이후 분석의 정확도를 확보

### 3. 키워드 의미 확장 (Word2Vec)
- 브랜드 마케팅 키워드를 Word2Vec 유사도로 확장 (마케팅 용어가 리뷰에서는 다양한 표현으로 등장하기 때문)
- 예: 마케팅 문구 "접지력, 경량성" → 소비자 표현 "가볍다, 미끄럽지 않다"
- 확장된 키워드로 WordCloud를 만들어 어떤 요소가 소비자에게 크게 와닿았는지 확인

### 4. 감성 분석
- 긍정·부정 기본 단어를 Word2Vec으로 확장해 감성 사전 구축
- 리뷰 토큰과 매칭해 **감성 점수 = 긍정 단어 수 − 부정 단어 수** 산출


| 지표 (살로몬 1,844건) | 값 |
|---|---|
| 긍정 단어가 포함된 리뷰 | 74.08% |
| 부정 단어가 포함된 리뷰 | 42.14% |
| 리뷰 평균 감성 점수 | 1.975 |

※ 한 리뷰에 긍정·부정 단어가 함께 있을 수 있어 두 비율의 합은 100%가 아닙니다.

### 5. 텍스트 분류
1. 리뷰 토큰별로 확장 키워드와 매칭
2. 카테고리별 매칭 횟수 집계
3. 매칭이 가장 많은 카테고리를 리뷰의 라벨로 지정
4. 매칭이 0건이면 **"분류 불가"** 처리 (분석 신뢰도 확보)

## 주요 발견

**팀 전체 인사이트: 브랜드 메시지는 소비자의 언어로 그대로 전달되지 않는다**
- 착화감·쿠셔닝·디자인처럼 제품 경험과 직결된 표현은 리뷰에서 많이 언급됨
- 기능성 소재·브랜드 가치(헤리티지)는 언급이 거의 없음 (0.1~0.8%)
- 브랜드가 내세운 용어를 소비자는 그대로 쓰지 않음

**살로몬:** 부정 리뷰의 비중이 상대적으로 높고, 마케팅 문구와 실제 사용 경험 간 차이가 있을 가능성 → 부정 리뷰의 원인 검증 필요

## 제안과 가설
| 제안 | 검증하고 싶은 가설 |
|---|---|
| 브랜드 언어 → 소비자 언어로 전환 | 소비자 표현 기반의 광고 문구(Hook)가 메시지 이해와 반응을 높일 수 있다 (추후 A/B 테스트) |
| 브랜드 감성 키워드 강조 | 복각·헤리티지 키워드는 브랜드 충성도와 연결될 수 있다 |
| 부정 리뷰 키워드 추적 | 구체적 키워드를 정량화해 반영하면 소비자 이탈을 줄일 수 있다 |

## 내 역할과 배운 점
- **팀장:** 대규모 데이터 처리를 분담하고, 회의로 분석 방법론을 교차 검증하며 협업 주도
- **살로몬 담당:** 수집 · 전처리 · 키워드 확장 · 감성 및 분류 분석 
- **배운 점:** API와 크롤링으로 데이터 소스를 수집·통합하고 전처리 파이프라인을 직접 설계, 수집부터 전략 제안까지 전체 흐름을 설계

## 한계와 다음 단계

## 실행 시 참고
- 네이버 검색 API 키는 코드에 포함하지 않았습니다. 본인의 Client ID / Secret을 발급받아 입력해야 합니다.
- 블로그·리뷰 원문은 타인의 저작물이라 **원본 데이터는 저장소에 포함하지 않았고**, 수집 코드로 재현할 수 있습니다.
